# 高中在线编程模块测试记录

测试日期：2026-09-13。

## 已修复问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| Python `sys.stdin.read()` 无法读取自定义输入，报 `OSError: [Errno 29] I/O error` | 仅替换了 `input()`，未接入标准输入 | 执行期间将 `sys.stdin` 指向输入流，结束后恢复；支持与 `input()` 混合读取 |
| 浏览器保存数据格式异常时课程无法初始化 | 对未经类型校验的 `completed` 调用 `.filter()` | 校验完成记录和草稿的数据类型，异常数据回退为空 |
| Python Worker 构造失败后再次运行仍失败，不会重新创建 Worker | 缓存了已拒绝的初始化 Promise | 初始化失败后清空缓存，允许重试 |
| 重复生成集成文件会产生重复 Vue 导入 | 集成脚本无条件插入组件导入 | 已有导入时跳过；重复生成输出一致 |

前三项已同步到现有前端 `public/online-programming`；集成脚本修复位于当前工作区。

## AI 无法使用的后续排查

实际运行的 8000 端口后端未加载新增接口：学生账号登录返回 200，携带有效登录令牌请求编程助教接口仍返回 404；3000 端口代理也返回 404。独立原型状态接口确认 AI 已配置。页面原先忽略状态码，把 404 误显示成配置不可用，发送问题时还会出现 HTML 解析错误。已修复并同步 tutor.js，401/403/404/502/503 及非 JSON 错误响应回归通过（node verify-tutor.cjs）。

后端重载尚未完成：已确认监听进程为 python（PID 10488），但 Windows 拒绝 Stop-Process，需在拥有该进程权限的终端手动重启项目后端。未停止数据库或前端。
