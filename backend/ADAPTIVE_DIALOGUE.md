# 自适应交流

三个场景分别使用固定的教师、宠物伙伴、编程助教身份。课程开场只使用教师身份，不读取宠物名字；课程资料作为数据传入，不作为角色指令。

每次对话及课程开场，后端读取该学生最近七天的心情（最多三条、日记每条最多300字）、练习（最多五条）、教师难度安排和当前场景最近互动。编程使用最近五次提交及本轮代码运行结果，不读取其他场景的聊天。没有记录时采用通用策略。

大模型先选择语气、节奏和引导方式，后端校验枚举并生成本轮附加提示词，再调用模型回复。模型不改写源码、身份或教师难度设置。失败或格式异常时使用温和的默认策略。规划结果不返回前端，也不作为学生消息保存。

回复规则要求自然调整、不主动引用私人日记或分数、不贴标签；学生追问个性化依据时诚实说明。涉及迫切危险时明确关心安全，不刻意含糊。既有教师关怀提醒继续独立工作。

部署：重启后端并更新前端构建。本次不新增数据库表，依赖此前的学习关怀、聊天场景及编程提交迁移。每轮增加一次短策略模型调用，前端聊天等待时间调整为90秒。

验证：21项后端回归、前端构建、三场景真实数据库读取检查。模型输出具有随机性，仍需在配置模型的运行环境观察实际交流效果；自动测试使用模拟模型响应。
