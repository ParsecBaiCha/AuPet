# MiroFish 后端 API 接口文档

## 概述

- **框架**: Flask (Python)
- **基础 URL**: `http://localhost:5001`
- **入口文件**: `server/run.py`
- **代码位置**: `server/app/api/`

## 通用说明

### 响应格式

所有接口统一返回 JSON 格式：

```json
{
  "success": true,
  "data": { ... },
  "message": "可选的成功消息",
  "error": "可选的错误消息"
}
```

### 认证

当前版本无认证机制。

### 2. 知识图谱管理 (`/api/graph`)

#### 2.1 获取项目详情

- **URL**: `GET /api/graph/project/<project_id>`
- **说明**: 获取指定项目的详细信息
- **路径参数**:
  - `project_id` (string): 项目ID

**响应示例**:
```json
{
  "success": true,
  "data": {
    "project_id": "proj_xxxx",
    "name": "项目名称",
    "status": "graph_completed",
    "graph_id": "zep_xxxx",
    "ontology": { ... },
    "files": [ ... ],
    "created_at": "2025-01-01T00:00:00"
  }
}
```

#### 2.2 列出所有项目

- **URL**: `GET /api/graph/project/list`
- **说明**: 获取项目列表
- **查询参数**:
  - `limit` (int, 可选): 返回数量限制，默认 50

**响应示例**:
```json
{
  "success": true,
  "data": [ ... ],
  "count": 10
}
```

#### 2.3 删除项目

- **URL**: `DELETE /api/graph/project/<project_id>`
- **说明**: 删除指定项目及其所有数据
- **路径参数**:
  - `project_id` (string): 项目ID

#### 2.4 重置项目

- **URL**: `POST /api/graph/project/<project_id>/reset`
- **说明**: 重置项目状态（用于重新构建图谱）
- **路径参数**:
  - `project_id` (string): 项目ID

#### 2.5 上传文件并生成本体

- **URL**: `POST /api/graph/ontology/generate`
- **说明**: 上传文档文件，分析并生成本体定义
- **Content-Type**: `multipart/form-data`
- **表单参数**:
  - `files` (file[], 必填): 上传的文件（支持 PDF/MD/TXT），可多个
  - `simulation_requirement` (string, 必填): 模拟需求描述
  - `project_name` (string, 可选): 项目名称
  - `additional_context` (string, 可选): 额外说明

**响应示例**:
```json
{
  "success": true,
  "data": {
    "project_id": "proj_xxxx",
    "project_name": "项目名称",
    "ontology": {
      "entity_types": [ ... ],
      "edge_types": [ ... ]
    },
    "analysis_summary": "本体分析摘要...",
    "files": [
      { "filename": "doc.pdf", "size": 12345 }
    ],
    "total_text_length": 50000
  }
}
```

#### 2.6 构建知识图谱

- **URL**: `POST /api/graph/build`
- **说明**: 根据项目ID异步构建知识图谱
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "project_id": "proj_xxxx",
    "graph_name": "图谱名称",
    "chunk_size": 500,
    "chunk_overlap": 50,
    "force": false
  }
  ```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "project_id": "proj_xxxx",
    "task_id": "task_xxxx",
    "message": "图谱构建任务已启动"
  }
}
```

#### 2.7 查询任务状态

- **URL**: `GET /api/graph/task/<task_id>`
- **说明**: 查询异步任务的执行状态和进度
- **路径参数**:
  - `task_id` (string): 任务ID

**响应示例**:
```json
{
  "success": true,
  "data": {
    "task_id": "task_xxxx",
    "status": "processing",
    "progress": 45,
    "message": "正在分块处理文本...",
    "created_at": "2025-01-01T00:00:00"
  }
}
```

#### 2.8 列出所有任务

- **URL**: `GET /api/graph/tasks`
- **说明**: 获取所有异步任务列表

#### 2.9 获取图谱数据

- **URL**: `GET /api/graph/data/<graph_id>`
- **说明**: 从 Zep 获取图谱的节点和边数据
- **路径参数**:
  - `graph_id` (string): Zep 图谱ID

**响应示例**:
```json
{
  "success": true,
  "data": {
    "graph_id": "zep_xxxx",
    "nodes": [ ... ],
    "edges": [ ... ],
    "node_count": 100,
    "edge_count": 200
  }
}
```

#### 2.10 删除图谱

- **URL**: `DELETE /api/graph/delete/<graph_id>`
- **说明**: 删除 Zep 中的图谱
- **路径参数**:
  - `graph_id` (string): Zep 图谱ID

### 3. 模拟仿真 (`/api/simulation`)

#### 3.1 实体读取

##### 3.1.1 获取图谱中的所有实体

- **URL**: `GET /api/simulation/entities/<graph_id>`
- **说明**: 获取图谱中已过滤的实体列表
- **路径参数**:
  - `graph_id` (string): 图谱ID
- **查询参数**:
  - `entity_types` (string, 可选): 逗号分隔的实体类型列表
  - `enrich` (bool, 可选): 是否获取相关边信息，默认 `true`

##### 3.1.2 获取单个实体详情

- **URL**: `GET /api/simulation/entities/<graph_id>/<entity_uuid>`
- **说明**: 获取单个实体的详细信息
- **路径参数**:
  - `graph_id` (string): 图谱ID
  - `entity_uuid` (string): 实体UUID

##### 3.1.3 按类型获取实体

- **URL**: `GET /api/simulation/entities/<graph_id>/by-type/<entity_type>`
- **说明**: 获取指定类型的所有实体
- **路径参数**:
  - `graph_id` (string): 图谱ID
  - `entity_type` (string): 实体类型
- **查询参数**:
  - `enrich` (bool, 可选): 是否获取相关边信息，默认 `true`

#### 3.2 模拟生命周期

##### 3.2.1 创建模拟

- **URL**: `POST /api/simulation/create`
- **说明**: 创建一个新的模拟实例
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "project_id": "proj_xxxx",
    "graph_id": "zep_xxxx",
    "enable_twitter": true,
    "enable_reddit": true
  }
  ```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "simulation_id": "sim_xxxx",
    "project_id": "proj_xxxx",
    "graph_id": "zep_xxxx",
    "status": "created",
    "enable_twitter": true,
    "enable_reddit": true,
    "created_at": "2025-01-01T00:00:00"
  }
}
```

##### 3.2.2 准备模拟环境

- **URL**: `POST /api/simulation/prepare`
- **说明**: 异步准备模拟环境（读取实体、生成Agent Profile、生成配置）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "entity_types": ["Student", "PublicFigure"],
    "use_llm_for_profiles": true,
    "parallel_profile_count": 5,
    "force_regenerate": false
  }
  ```

**响应示例**:
```json
{
  "success": true,
  "data": {
    "simulation_id": "sim_xxxx",
    "task_id": "task_xxxx",
    "status": "preparing",
    "message": "准备任务已启动",
    "already_prepared": false,
    "expected_entities_count": 68,
    "entity_types": ["Student", "Professor"]
  }
}
```

##### 3.2.3 查询准备任务进度

- **URL**: `POST /api/simulation/prepare/status`
- **说明**: 查询模拟准备任务的进度
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "task_id": "task_xxxx",
    "simulation_id": "sim_xxxx"
  }
  ```

##### 3.2.4 获取模拟状态

- **URL**: `GET /api/simulation/<simulation_id>`
- **说明**: 获取指定模拟的当前状态
- **路径参数**:
  - `simulation_id` (string): 模拟ID

##### 3.2.5 列出所有模拟

- **URL**: `GET /api/simulation/list`
- **说明**: 获取模拟列表
- **查询参数**:
  - `project_id` (string, 可选): 按项目ID过滤

##### 3.2.6 获取历史模拟

- **URL**: `GET /api/simulation/history`
- **说明**: 获取历史模拟列表（带项目详情）
- **查询参数**:
  - `limit` (int, 可选): 返回数量限制，默认 20

#### 3.3 Profiles 与配置

##### 3.3.1 获取 Agent Profiles

- **URL**: `GET /api/simulation/<simulation_id>/profiles`
- **说明**: 获取模拟的 Agent Profile
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `platform` (string, 可选): 平台类型 (`reddit`/`twitter`)，默认 `reddit`

##### 3.3.2 实时获取 Agent Profiles

- **URL**: `GET /api/simulation/<simulation_id>/profiles/realtime`
- **说明**: 在生成过程中实时查看 Agent Profile
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `platform` (string, 可选): 平台类型，默认 `reddit`

##### 3.3.3 实时获取配置

- **URL**: `GET /api/simulation/<simulation_id>/config/realtime`
- **说明**: 在生成过程中实时查看模拟配置
- **路径参数**:
  - `simulation_id` (string): 模拟ID

##### 3.3.4 获取模拟配置

- **URL**: `GET /api/simulation/<simulation_id>/config`
- **说明**: 获取 LLM 生成的完整模拟配置
- **路径参数**:
  - `simulation_id` (string): 模拟ID

##### 3.3.5 下载模拟配置

- **URL**: `GET /api/simulation/<simulation_id>/config/download`
- **说明**: 下载 `simulation_config.json` 文件
- **路径参数**:
  - `simulation_id` (string): 模拟ID

##### 3.3.6 下载运行脚本

- **URL**: `GET /api/simulation/script/<script_name>/download`
- **说明**: 下载模拟运行脚本文件
- **路径参数**:
  - `script_name` (string): 脚本名称
    - `run_twitter_simulation.py`
    - `run_reddit_simulation.py`
    - `run_parallel_simulation.py`
    - `action_logger.py`

##### 3.3.7 直接生成 Profiles

- **URL**: `POST /api/simulation/generate-profiles`
- **说明**: 直接从图谱生成 Agent Profile（不创建模拟）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "graph_id": "zep_xxxx",
    "entity_types": ["Student"],
    "use_llm": true,
    "platform": "reddit"
  }
  ```

#### 3.4 模拟运行控制

##### 3.4.1 启动模拟

- **URL**: `POST /api/simulation/start`
- **说明**: 开始运行模拟
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "platform": "parallel",
    "max_rounds": 100,
    "enable_graph_memory_update": false,
    "force": false
  }
  ```

**参数说明**:
- `platform`: 运行平台，可选值 `twitter` / `reddit` / `parallel`（默认）
- `max_rounds`: 最大模拟轮数（可选）
- `enable_graph_memory_update`: 是否将 Agent 活动更新到 Zep 图谱
- `force`: 强制重新开始（会停止运行中的模拟并清理日志）

##### 3.4.2 停止模拟

- **URL**: `POST /api/simulation/stop`
- **说明**: 停止正在运行的模拟
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx"
  }
  ```

#### 3.5 实时监控

##### 3.5.1 获取运行状态

- **URL**: `GET /api/simulation/<simulation_id>/run-status`
- **说明**: 获取模拟运行实时状态（用于前端轮询）
- **路径参数**:
  - `simulation_id` (string): 模拟ID

**响应示例**:
```json
{
  "success": true,
  "data": {
    "simulation_id": "sim_xxxx",
    "runner_status": "running",
    "current_round": 5,
    "total_rounds": 144,
    "progress_percent": 3.5,
    "simulated_hours": 2,
    "total_simulation_hours": 72,
    "twitter_running": true,
    "reddit_running": true,
    "twitter_actions_count": 150,
    "reddit_actions_count": 200,
    "total_actions_count": 350,
    "started_at": "2025-01-01T10:00:00",
    "updated_at": "2025-01-01T10:30:00"
  }
}
```

##### 3.5.2 获取详细运行状态

- **URL**: `GET /api/simulation/<simulation_id>/run-status/detail`
- **说明**: 获取模拟运行详细状态（包含所有动作）
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `platform` (string, 可选): 过滤平台 (`twitter`/`reddit`)

##### 3.5.3 获取动作历史

- **URL**: `GET /api/simulation/<simulation_id>/actions`
- **说明**: 获取模拟中 Agent 的动作历史（分页）
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `limit` (int, 可选): 返回数量，默认 100
  - `offset` (int, 可选): 偏移量，默认 0
  - `platform` (string, 可选): 过滤平台
  - `agent_id` (int, 可选): 过滤 Agent ID
  - `round_num` (int, 可选): 过滤轮次

##### 3.5.4 获取时间线

- **URL**: `GET /api/simulation/<simulation_id>/timeline`
- **说明**: 获取按轮次汇总的模拟时间线
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `start_round` (int, 可选): 起始轮次，默认 0
  - `end_round` (int, 可选): 结束轮次

##### 3.5.5 获取 Agent 统计

- **URL**: `GET /api/simulation/<simulation_id>/agent-stats`
- **说明**: 获取每个 Agent 的统计信息（活跃度、动作分布等）
- **路径参数**:
  - `simulation_id` (string): 模拟ID

#### 3.6 数据库查询

##### 3.6.1 获取帖子

- **URL**: `GET /api/simulation/<simulation_id>/posts`
- **说明**: 从 SQLite 数据库获取模拟中的帖子
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `platform` (string, 可选): 平台类型 (`twitter`/`reddit`)，默认 `reddit`
  - `limit` (int, 可选): 返回数量，默认 50
  - `offset` (int, 可选): 偏移量

##### 3.6.2 获取评论

- **URL**: `GET /api/simulation/<simulation_id>/comments`
- **说明**: 从 SQLite 数据库获取模拟中的评论（仅 Reddit）
- **路径参数**:
  - `simulation_id` (string): 模拟ID
- **查询参数**:
  - `post_id` (string, 可选): 过滤帖子ID
  - `limit` (int, 可选): 返回数量，默认 50
  - `offset` (int, 可选): 偏移量

#### 3.7 Agent 采访 (Interview)

##### 3.7.1 采访单个 Agent

- **URL**: `POST /api/simulation/interview`
- **说明**: 采访单个 Agent（需要模拟环境处于运行状态）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "agent_id": 0,
    "prompt": "你对这件事有什么看法？",
    "platform": "twitter",
    "timeout": 60
  }
  ```

##### 3.7.2 批量采访

- **URL**: `POST /api/simulation/interview/batch`
- **说明**: 批量采访多个 Agent（可使用不同问题）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "interviews": [
      { "agent_id": 0, "prompt": "你对A有什么看法？", "platform": "twitter" },
      { "agent_id": 1, "prompt": "你对B有什么看法？" }
    ],
    "platform": "reddit",
    "timeout": 120
  }
  ```

##### 3.7.3 采访所有 Agent

- **URL**: `POST /api/simulation/interview/all`
- **说明**: 使用相同问题采访所有 Agent
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "prompt": "你对这件事整体有什么看法？",
    "platform": "reddit",
    "timeout": 180
  }
  ```

##### 3.7.4 获取采访历史

- **URL**: `POST /api/simulation/interview/history`
- **说明**: 获取 Interview 历史记录
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "platform": "reddit",
    "agent_id": 0,
    "limit": 100
  }
  ```

#### 3.8 环境控制

##### 3.8.1 检查环境状态

- **URL**: `POST /api/simulation/env-status`
- **说明**: 检查模拟环境是否存活（可以接收 Interview 命令）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx"
  }
  ```

##### 3.8.2 关闭模拟环境

- **URL**: `POST /api/simulation/close-env`
- **说明**: 优雅关闭模拟环境（不同于 `/stop` 的强制终止）
- **Content-Type**: `application/json`
- **请求体**:
  ```json
  {
    "simulation_id": "sim_xxxx",
    "timeout": 30
  }
  ```
