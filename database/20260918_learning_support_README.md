# 学习关怀与教师调难度

部署时先在现有业务数据库执行 `20260918_learning_support.sql`，然后重启后端并重新构建前端。迁移只新增四张表，可重复执行，不修改已有业务数据。

学生在成长日记选择“难过”、主动求助、对话命中情绪/学业相关词或完成测验得分低于 60 时，写入教师学习关怀提醒。同一学生、同一来源、同一天合并提醒；同日已跟进提醒不会因重复提交重新变为待关注。关键词只提供待确认线索，低分单独标为学习困难，不作为情绪结论。

教师顶部“学习关怀”每 30 秒刷新待关注数量，进入“干预管理”可查看、备注并选择基础练习、保持现状或恢复正常难度。仅学生当前班级的任课教师可访问。基础练习针对学生所有后续 AI 测验，保留年级及主题、简化认知要求；不改变已生成题目，不修改全班共享题库，持续至教师恢复。基础题生成失败会提示重试，不会回退到原难度。干预和操作记录在同一事务中保存。

验收：学生选择难过或点击“做题有点难，告诉老师” → 任课教师刷新学习关怀 → 查看与干预 → 选择基础练习并保存 → 学生重新生成题目，看到“老师为你安排了基础练习” → 教师恢复正常难度 → 再次生成使用正常题库。

运行后端回归：`python -B -m unittest discover -s backend -p test_learning_support.py`。

当前限制：提醒为站内轮询；沿用项目既有登录机制和测验提交格式。题目认知难度由模型按指令生成，尚无独立难度标定；测验提交仍使用前端携带的题目及答案，未来可迁移为服务端试卷会话以防篡改。
